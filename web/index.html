Welcome to Marionette

First time here? This short tour takes you from sensor placement to trackers on your body. Your progress is saved.

Welcome to Marionette

Marionette turns one or more Kinect sensors into full-body tracking for VR. Each sensor watches you from a different angle; the fusion engine merges every view into one stable skeleton and streams tracker poses to SteamVR or straight to a Quest headset over Wi-Fi.

Opposed viewpoints structurally remove the two classic single-Kinect failures: front/back flips and self-occlusion dropouts.

Choose your path

Two ways to get trackers into your game. You can run both endpoints at once, but pick one to set up first.

Quest standalone

simplest
  • VRChat OSC over Wi-Fi - no PCVR stream needed
  • No SteamVR, no driver, no playspace calibration
  • The PC only runs Marionette and the Kinects
  • Up to 8 trackers; start with 3-point

PCVR (SteamVR)

most compatible
  • Works in any OpenVR app via ALVR, Virtual Desktop, Link, or a wired headset
  • Trackers appear as real SteamVR devices (MN-*)
  • Needs a one-time driver install and a playspace anchor calibration

Place your sensors

Mount sensors at head height (1.6-2.0 m), tilted slightly down, with the play-area center 2-3.5 m away. Depth noise grows with range - past about 4 m a sensor contributes little.

  • One Kinect v2 per PC - a hard SDK limit (multiple v1s can share a PC).
  • Never overlap two Kinect v1s - their projected IR dot patterns interfere badly. A v1 + v2 mix is clean, as is v2 + v2.
  • One USB3 controller per v2 when planning multi-v2 rigs - separate PCIe USB3 cards, not one card's ports.
  • Mount rigidly: a bumped tripod means redoing pair calibration for that sensor.

See yourself

Open the Skeleton tab to watch the live fused body: front and top-down views, sensor positions, and the tracker diamonds being streamed out. If the skeleton is solid while you turn in place, the rig is healthy.

Body looks wrong? If it faces the wrong way, mirrors your left and right, or hangs upside down, that is a projection error - use the Projection health panel on the Skeleton tab. It flags accuracy problems live and gives you Flip X / Y / Z and Swap L/R switches to correct them in one click.

No hardware yet? The bundled demo runs two synthetic sensors through the real fusion pipeline - a zero-hardware dry run of everything on this dashboard.

Calibrate - in this order

  1. Pair alignment multi-sensor rigs - aligns each extra sensor to the reference. Stand in the overlap and move your limbs slowly; accept under 2-3 cm RMSE.
  2. Body model - a 15-30 s capture of your bone lengths. Redo it per person, not per session.
  3. Playspace anchor PCVR only - aligns Marionette's world with the SteamVR playspace using a tracked controller. The OSC path never needs it.

Connect your headset

Quest - VRChat OSC

  1. Find the headset IP: Settings > Wi-Fi > your network > details. A static DHCP lease helps.
  2. Point the osc endpoint at it: host = the headset IP, port 9000.
  3. In VRChat: Action Menu > Options > OSC > Enabled.
  4. Run Marionette, then run VRChat's FBT calibration (stand straight, arms out, confirm).

SteamVR

not built in this binary
  1. Register the driver once with scripts/install-driver.ps1 (or .sh).
  2. Add the openvr endpoint (127.0.0.1:24190) to your config.
  3. Start SteamVR via ALVR / Virtual Desktop / Link, then run Marionette. Trackers appear as MN-WAIST, MN-LFOOT, and so on.
  4. Assign roles: SteamVR > Settings > Controllers > Manage Trackers. SteamVR remembers per serial.
  5. Quest 2: lower the video bitrate in ALVR / Virtual Desktop. Tracker data is tiny - the video stream is what competes for bandwidth.

You are set

Trackers should now sit on your body and stay there. Recalibrate only when something changes:

  • Sensor moved, bumped, or remounted -> redo Pair for that sensor.
  • Different person using the rig -> redo the Body model.
  • SteamVR room setup, playspace recenter, or a different streaming app -> redo the Playspace anchor. Re-running it at session start is cheap insurance.
  • Trackers drift or sit offset -> anchor first; if turning in place doubles your limbs, redo Pair.

Watch the Events tab - warnings surface there first. The full reference lives in the repo's docs folder: USAGE.md and CALIBRATION.md.
